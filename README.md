# pdf-merger

Aplikasi Streamlit modern untuk menggabungkan banyak file PDF dan Word (.docx/.doc) secara per-baris maupun masal dalam format ZIP.

## Fitur Utama
- 📄 **Support PDF & Word (.docx/.doc)**: Mengonversi dokumen Word ke PDF secara otomatis di memori.
- 📁 **File Utama & Lampiran Multiple**: Bisa mengunggah banyak file sekaligus di setiap baris.
- 🔀 **Atur Urutan Posisi (Re-ordering)**: Mengatur urutan posisi gabungan file dengan tombol ⬆️ dan ⬇️.
- 👁️ **Live Interactive PDF Viewer**: Preview hasil gabungan PDF langsung di browser.
- 💾 **Rename & Single Download**: Unduh per-baris dengan nama file kustom.
- 📦 **Bulk ZIP Download**: Unduh seluruh hasil gabungan sekaligus dalam 1 file ZIP.

## Cara Menjalankan

1. Install dependensi:
   ```bash
   pip install -r requirements.txt
   ```
2. Jalankan Streamlit:
   ```bash
   streamlit run app.py
   ```
